# Competitive Intelligence Agent

An AI-powered agent that monitors your competitors and generates daily reports. Configure it once with your company and competitor details, and it runs on a daily schedule — collecting data, analysing it with Claude, and producing HTML reports and Markdown digests.

## How it works

The pipeline runs in five phases each day:

1. **Firehose** — streams competitor mentions (press, news, web) via a real-time tap
2. **Firecrawl** — deep-scrapes competitor product pages and job listings
3. **News & SEC** — fetches news articles and SEC filings for public competitors
4. **Snapshots** — Claude Opus summarises each competitor's activity for the day
5. **Comparison report** — Claude Opus produces a multi-month strategic comparison across all competitors, saved as an HTML report

## Quick start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Configure your company and competitors
cp company.example.yaml company.yaml   # edit with your details
cp .env.example .env                   # add your API keys

# 3. Run the interactive wizard (alternative to editing company.yaml manually)
python main.py --setup

# 4. Bootstrap Firehose (one-time — creates your tap and sync rules)
python main.py --bootstrap

# 5. Run the full pipeline for the first time (pull 30 days of history)
python main.py --run-now --news-days 30

# 6. Start the daily scheduler (runs at 06:00 UTC by default)
python main.py --schedule
```

## CLI reference

```
python main.py --setup              Interactive wizard → generates company.yaml
python main.py --bootstrap          Create Firehose tap + sync rules (run once)
python main.py --run-now            Run the full pipeline immediately
python main.py --schedule           Start the daily scheduler (default 06:00 UTC)

Options:
  --report-only                     Skip data collection, regenerate report only
  --news-days N                     Days of news/SEC data to pull (default: 1)
  --skip-firehose                   Skip Firehose pull
  --skip-firecrawl                  Skip Firecrawl scraping
```

## Configuration

### company.yaml

Describes your company and the competitors to track. Start from the example:

```bash
cp company.example.yaml company.yaml
```

Each competitor entry supports:

| Field | Description |
|-------|-------------|
| `name` | Display name |
| `press_room` | Press/news page URL |
| `blog` | Blog URL |
| `products` | Products/solutions page URL |
| `careers` | Careers page URL |
| `ticker` | Stock ticker for SEC filings (e.g. `HUBS`) |
| `news_query` | Custom news search string (defaults to the competitor name) |

### Environment variables

All config is in `.env` (copy from `.env.example`). Optional scheduler overrides:

```bash
DAILY_RUN_HOUR=6      # UTC hour for daily run (default: 6)
DAILY_RUN_MINUTE=0    # UTC minute (default: 0)
INTEL_DB_PATH=./competitive_intel.db   # SQLite DB location
REPORTS_DIR=./reports                  # output directory for reports
```

## Outputs

- **`reports/report_YYYY-MM-DD.html`** — full multi-month competitive comparison
- **`reports/digest_YYYY-MM-DD.md`** — daily Markdown digest per competitor
- **`competitive_intel.log`** — pipeline run log
- **`competitive_intel.db`** — SQLite database of all collected intel
